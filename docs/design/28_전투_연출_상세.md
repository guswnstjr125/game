# 다크 레기온 — 전투 연출 상세 설계

> **문서 역할**: 전투 VFX/SFX/카메라/타이밍을 로직과 분리해 구현하는 명세
> **참조 문서**: 06_전투_코어_상세설계, 27_UI_바인딩_설계

---

## 1. 원칙

- 연출은 `PresentationEvent` 기반으로만 반응
- 로직 결과를 절대 바꾸지 않음 (Presentation Only)
- Queue 실행과 연출은 독립 타임라인

---

## 2. 액션별 연출 매핑

| ActionType | VFX | SFX | 카메라 |
|---|---|---|---|
| DamageAction | Slash/Impact | hit_light/hit_heavy | 짧은 shake(0.12s) |
| ApplyStatusAction | 상태아이콘 팝업 | status_apply | 없음 |
| HealAction | 녹색 파티클 | heal_chime | 없음 |
| SummonAction | 소환 원형 glyph | summon_portal | zoom in 0.2s |
| DeathAction | dissolve + soul smoke | death_soft | 없음 |
| ExecuteAction | cross flash + blackout 1f | execute_hit | strong shake(0.18s) |

---

## 3. 타이밍 표준

| 단계 | 시간 |
|---|---|
| Intent 표시 | Enemy turn 시작 +0.0s |
| 카드 사용 클릭 반응 | 0.08s 이내 |
| 단일 공격 전체 연출 | 0.24s |
| 광역 공격 전체 연출 | 0.35s |
| 상태이상 아이콘 반영 | 액션 후 +0.05s |
| 턴 종료 패 버림 연출 | 0.3s |

---

## 4. 보스 페이즈 전환 연출

| 보스 | 페이즈 전환 연출 |
|---|---|
| 굶주림의 사제 | vignette 강화 + 저음 hit |
| 재의 대군주 | 화면 열기 왜곡 + ember rain |
| 혈육의 어머니 | 혈액 튀김 오버레이 |
| 무죄의 심판관 | 화면 중앙 십자가 플래시 |
| 절망의 군주 | 화면 desaturate + 저주 글리프 |

공통 이벤트: `PresentationEvent.BossPhaseChanged`

---

## 5. 성능 기준

| 항목 | 기준 |
|---|---|
| 모바일 최소 FPS | 45 |
| 동시 파티클 수 | 120 이하 |
| 보스 연출 프레임 드랍 | 10% 이내 |
| 풀 전투(턴당 10액션) | 16ms/frame 목표 |

---

## 6. 접근성/가독성

- 색약 모드: Burn/Poison/Weak/Vuln 아이콘 외곽 형태로 구분
- 화면 흔들림 옵션: Off/Low/Default
- 연출 속도 옵션: x1 / x1.5 / x2 (로직은 동일)
