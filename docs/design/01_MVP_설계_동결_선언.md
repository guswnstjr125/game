### D-01. 피해 공식

**배경**: ATK/DEF는 정의돼 있으나 DEF가 피해에 적용되는 방식이 어느 문서에도 없었다 (`06` §11 Damage Pipeline에 DEF 단계 누락).

**결정**

```
공격 피해 = max(1, floor( (기본피해 × 치명배율 × Weak배율 − DEF) × Vulnerable배율 ))

기본피해     : 유닛 공격 = 공격자 FinalAtk / 카드 피해 = 카드 Value
치명배율     : 치명타 1.5, 그 외 1.0
Weak배율     : 공격자(유닛)가 Weak면 0.75, 그 외 1.0  (플레이어 카드 피해에는 적용 안 함)
DEF          : 대상 FinalDef (Front 위치 보너스 DEF +1 포함, Position_Bonus)
Vulnerable배율: 대상이 Vulnerable이면 1.25, 그 외 1.0
```

| 규칙 | 내용 |
|---|---|
| 계산 순서 | 기본피해 → 치명 → Weak → DEF 차감 → Vulnerable → 내림(floor) → 최소 1 → Shield → HP |
| 최소 피해 | 공격 피해(유닛 공격·카드 피해)는 **최소 1** (DEF가 높아도 0이 되지 않음) |
| IgnoreDefense | DEF = 0으로 계산 (Burn·Poison 틱, `방어 무시` 효과) |
| 상태이상 틱 | Burn/Poison 틱 피해 = 스택 값 그대로. DEF·Weak·Vulnerable 미적용, **Shield는 적용** (`06` §11 IgnoreShield=false 기본) |
| 플레이어 | 플레이어 DEF = 0. Shield만 적용 |
| 관통 효과 | "방어 무시 50%" 등 부분 관통은 DEF × (1 − 관통률)을 내림 후 차감 |

**검증 예시 (1층 노드 1)**

| 공격 | 계산 | 피해 |
|---|---|---|
| 굶주린 구울(적, ATK5) → 뼈 병사(Front, DEF1+1) | 5 − 2 | 3 |
| 뼈 병사(ATK3) → 굶주린 구울(적, Front, DEF1+1) | max(1, 3 − 2) | 1 |
| 저주받은 해골(ATK5, Weak) → 구울(Front, DEF2, Vulnerable) | floor((3.75 − 2) × 1.25) | 2 |

> Front 보너스가 적에게도 적용되어 1층 아군 Lv1의 실질 피해가 낮다. 수치 조정은 `35_운영_검증_팩.xlsx` 밸런스_백로그에서 시뮬레이터 결과로 판단하고, 공식 자체는 변경하지 않는다.

### D-02. 소환 턴 행동

**배경**: 몬스터를 소환한 턴에 행동할 수 있는지가 정의되지 않았다.

**결정**

| 규칙 | 내용 |
|---|---|
| 소환 턴 행동 | Main Phase에 소환한 몬스터는 **같은 턴 Command Phase에 행동 가능** (공격/방어/스킬 1회) |
| 토큰 | 스킬·액션으로 소환된 토큰도 동일하게 소환 턴 행동 가능 |
| Wave 전환 | Wave 2 진입 시 유지된 아군 몬스터는 정상 행동 (`04` §11) |
| 적 소환 | 적이 Enemy Phase에 소환한 유닛은 **다음 Enemy Phase부터** 행동 (Intent 표시 후 행동 원칙) |
| 희생 | 소환 턴에도 희생 가능 (Soulbound 제외, `13` §1) |

### D-03. 융합 시점·비용·결과 비율

**배경**: `04`·`13`·`16`·`03`의 융합 서술이 서로 달랐다 (맵 해금 vs 전투 중 실행, 30/70 비율 vs 레시피 우선, 비용 유무, Mutation 풀 미정의).

**결정 — 시점**

| 규칙 | 내용 |
|---|---|
| 실행 위치 | **전투 중 Main Phase** (`13` §4 RequestFusion). 전투 밖에서는 불가 |
| 재료 | **손패**의 같은 레벨 Monster 카드 2장. 필드 유닛·토큰은 재료 불가 |
| 해금 = 융합 충전 | "3스테이지마다 해금"은 **융합 충전(FusionCharge) +1**로 해석. 각 층 노드 3·6·9 클리어 시 +1 |
| 충전 | 런 시작 0, 최대 보유 3, 층 이동 시 유지. 융합 1회 = 충전 1 소모 |
| 1~2층 | 1층 노드 3 클리어부터 융합 가능 (첫 충전). 3층 노드 3 융합 성소는 **튜토리얼 + 충전 소모 없는 무료 융합 1회** |

**결정 — 비용·결과**

| 융합 | Crystal 비용 | 결과 |
|---|---|---|
| Lv1 + Lv1 | 2 | Lv2 카드 1장 |
| Lv2 + Lv2 | 3 | Lv3 카드 1장 |
| Lv3 + Lv3 | — | **MVP 불가** (Validate 실패 `LEVEL_CAP`). Lv4는 Post-MVP |

- 재료 2장 영구 소멸(DeadCard), 결과 카드는 **손패**로 들어오고 이후 덱에 영구 편입
- 결과 카드는 같은 턴에 Crystal이 있으면 즉시 소환 가능
- `REL_RARE_002 융합의 촉매`(+1레벨 15%)는 결과가 Lv3이면 발동하지 않음

**결정 — 결과 판정 순서**

```
1. 고정 레시피(Fusion_Recipes, A·B 순서 무관)가 있으면 → 100% 고정 결과
2. 없으면 랜덤:
   - 같은 클래스      : 80% 해당 클래스 Lv+1 / 20% NEU Lv+1
   - NEU + 클래스     : 50% 클래스 Lv+1 / 50% NEU Lv+1
   - 서로 다른 클래스 : 50% A 클래스 Lv+1 / 50% B 클래스 Lv+1
   - 개별 몬스터 선택 : Fusion_RandomPool 해당 클래스·레벨 행의 Weight 비례
3. 해당 풀이 비어 있으면 → 재료 A 클래스 Lv+1 중 Common 균등 랜덤 (`13` §3.4 Fallback)
```

| 정리 항목 | 결정 |
|---|---|
| `04` §7 "고정 30% / 랜덤 70%" | 확률이 아니라 **콘텐츠 구성 목표**(전체 조합 중 고정 레시피 비중)로 해석. 판정에 사용하지 않음 |
| Mutation 10% (`13`, `23`) | **MVP 비활성**. 해당 10%는 클래스 결과에 합산 (70+10=80%). Mutation·Abyss Fusion은 Post-MVP |
| FUS_009 (뼈 병사 + 해골 토큰) | 토큰은 카드가 아니므로 **MVP 비활성**. 동일 결과는 ~~FUS_002~~ **FUS_014**로 획득 (D-22: FUS_002도 재료에 카드가 없어 비활성) |

### D-07. 시작 클래스 카드 해금

`Cards_FloorUnlock.UnlockFloor`는 그 카드 클래스가 시작 클래스가 아닐 때의 일정이다 (NEC 시작 누적 32/48/68/86/92).

ELE·BEA·HOL 카드는 `UnlockFloor_IfStartClass = 1`. 그 클래스로 시작한 런에서만 유효 해금층이 1이다. 다른 클래스 카드의 `UnlockFloor`는 유지한다. ELE 시작 누적 50/54/70/88/92 (D-17), HOL 시작 누적 52/68/86/88/92, BEA 시작 누적 52/64/70/86/92. NEC·NEU 카드는 이미 1층 해금이라 해당 없음.

Poison 최대 스택은 **20**이다. 틱은 스택 수 그대로이고, 전투가 끝날 때 제거된다. Wave가 바뀌어도 스택은 남으며 20을 넘는 추가는 적용하지 않는다.

### D-09. 스케일 정수화

스테이지인덱스는 0~8이다. 일반 HP/ATK/DEF는 `16` §2 식을 반올림해 Floor_Scale과 같게 한다. 보스 DEF는 인덱스 8의 반올림 전 DEF × 1.5를 **내림**한다 (1/2/2/3/3).

### D-10. 이벤트 8종

공통 4종(악마 계약, 피의 제단, 저주 상자, 영혼 감옥)에 방랑 상인, 잊힌 제단, 어둠의 내기, 묘지의 속삭임을 더한다. 각 층의 풀은 공통 4종과 그 층 신규 2종이다. 가중치는 `Event_FloorPool` (층별 합 100%).

### D-11. 맵 경로

MVP 맵은 층당 9노드 **단일 경로**다. 노드마다의 2지선다와 분기 맵은 Post-MVP로 남긴다.

### D-12. NEU 언락

`UNL_CLASS_NEU`: Soul 150, 조건 `ClearFloor4Once`. 5클래스 승리 업적(`ACH_ALL_CLASS_WIN`)의 전제다.

### D-13. 구현 단계

1단계: 1~2층, NEC, 카드 약 30장, 전투 UI·단일 경로 맵·세이브가 포함된 플레이 가능 빌드. 2단계: 3~5층과 나머지 클래스·카드·메타·연출·시뮬레이터. 상세 주차는 `02` §4.

### D-14. HP 손실 목표 하향 (D-04 개정)

**배경**: D-04 목표(일반 5~10 / 엘리트 12~18 / 보스 20~30)는 층당 손실이 52~94인데, PlayerHP는 층 간 유지되고 고정 회복은 층당 휴식 1회(80 × 30% = 24)뿐이다. 중간값 기준 2층 엘리트에서 HP가 바닥나 런 클리어율 30~45%와 양립하지 않았다.

**결정**: 전투당 평균 PlayerHP 손실 목표를 일반 **2~4** / 엘리트 **6~10** / 보스 **10~15**로 낮춘다. 층 클리어 회복 같은 신규 회복 수단은 추가하지 않는다 (MVP 범위 유지).

| 기준 | 층당 손실 (일반 4 + 엘리트 1 + 보스 1) | 휴식 회복 | 층당 순손실 | 5층 누적 (시작 80) |
|---|---|---|---|---|
| 최솟값 | 8 + 6 + 10 = 24 | 24 | 0 | 80 유지 |
| 중간값 | 12 + 8 + 12.5 = 32.5 | 24 | −8.5 | 약 38 남음 |
| 최댓값 | 16 + 10 + 15 = 41 | 24 | −17 | 5층 보스에서 사망권 |

중간값 덱이 클리어하고 최댓값 덱이 마지막 층에서 무너지는 분포가 런 클리어율 30~45%와 맞는다. Rest를 강화로 쓰면 그 층 회복 24가 빠진다는 점이 휴식 노드의 선택 압력이다.

### D-15. 보스 유물 희생 보너스 턴당 1회

**배경**: `REL_BOSS_1F`(희생할 때마다 Crystal +1)를 얻으면 2층부터 D-04의 피의 잔 너프가 무효가 된다. `REL_BOSS_5F`(아군 사망마다 Crystal +1)도 5층 엘리트 유물 풀에 있어 같은 문제가 있다.

**결정**

| 유물 | 변경 후 효과 |
|---|---|
| `REL_BOSS_1F` 굶주린 자의 뼈 | **턴당 첫 희생 시** Crystal +1 추가 (피의 잔과 중첩) |
| `REL_BOSS_5F` 절망의 파편 | 아군 사망 시 Draw +1. Crystal +1은 **턴당 첫 사망에만** |

NEC가 두 유물과 피의 잔을 모두 가진 경우 턴당 첫 희생에서 Lv1·파편 기준 Crystal +3(본체 +1, 잔 +1, 뼈 +1)을 받고, 같은 턴 이후 희생은 본체 보상만 받는다.

### D-16. 보스 보상 유물

**배경**: D-06으로 클래스 시작 유물이 고정됐는데, `03`의 1~4층 보스 보상이 바로 그 시작 유물(`REL_CURSED_SKULL`, `REL_CORRUPT_CHALICE`, `REL_ABYSS_HEART`, `REL_FORBIDDEN_CANDLE`)이었다. Excel `14_보스_패턴.xlsx` Boss_List는 이미 `REL_BOSS_*`를 보상으로 쓴다.

**결정**: 층 보스 보상 유물은 `REL_BOSS_1F`~`REL_BOSS_5F`로 통일한다. 5층 보스는 런 승리로 끝나므로 `REL_BOSS_5F`는 보상 표기만 두고 실효가 없다 (5층 엘리트 유물 풀에서는 획득 가능).

### D-17. ELE 시작 클래스 해금 (D-07 보완)

**배경**: D-07이 HOL·BEA에만 적용돼, ELE로 시작하면 1층 드롭 ELE 카드가 2장뿐이었다.

### D-18. 1층 보스 Phase 3 2회 공격 유지

**배경**: `37`에 "Phase 3 2회 공격에도 풀피 Front 한 마리는 버틴다"고 적혀 있었으나, D-01 기준 ATK 8 × 2회면 NEC 시작 몬스터(뼈 병사·구울·역병 쥐·떠돌이 용병)는 Front에서 모두 사망한다.

### D-19. A3 잔여 동기화 (Boss_Phase · 마스터통합)

**배경**: D-05·E2로 `14` Boss_List/TurnCycle Damage·Boss_Stats 배율·`10` Enemies·`20` md는 8/9/11/14/16으로 맞춰졌으나, `14` Boss_Phase 서술 칸에 ATK 12(구 ×2.0)가 남아 구현/검수 시 혼동을 줄 수 있었다. 통합본 `Cards`도 16행만 남아 `08`과 어긋났다.
