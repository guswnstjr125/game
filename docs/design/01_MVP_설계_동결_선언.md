# 다크 레기온 — MVP 설계 동결 선언 (Design Freeze)

> 목적: 구현 착수 시 해석 차이 없이 동일 기준으로 작업하기 위한 단일 기준서  
> 적용 범위: MVP (1~5층 Vertical Slice)  
> 기준 문서 우선순위: `03_MVP_전층_스펙.md` > `02_개발_로드맵.md` > `06_전투_코어_상세설계.md`/`07_TriggerBus_상세설계.md`/`08_RuntimeFactory_상세설계.md`/`09_BattleField_슬롯_상세설계.md` > `10_카드_런타임_매핑_상세.md`/`24_콘텐츠_런타임_상세.md`/`22_보스_패턴_설계.md`/`25_MVP_보완_시스템_상세.md` > 기타

---

## 1. 동결 범위

- 맵: 층당 9노드 단일 경로 (5층 총 45노드)
- 노드 구성: Battle 4 / Event 2 / Elite 1 / Rest 1 / Boss 1
- 상점: 2층+ 노드6 Event 30% 치환 옵션
- Treasure/Mimic: MVP 미등장 (입력 시 Treasure 안전 폴백만 허용)
- 카드: 92장 CardId 기반 실행
- 적: 28종 + 보스 5종
- 이벤트: MVP 4종
- 상태이상: 8종 (Burn 최대 20)

---

## 2. 동결 제외(Post-MVP)

- 분기 맵(최소 루트 3개, 교차 연결)
- Treasure/Mimic 실제 노드 등장
- 로컬라이제이션 확장
- Save 암호화 고도화

---

## 3. 문서 충돌 시 판정 규칙

1) `03_MVP_전층_스펙.md`를 최우선으로 따른다.  
2) 수치 충돌은 Excel 정본(`04/06/08/10/12/14`)을 우선한다.  
3) 런타임 구조 충돌은 `06_전투_코어_상세설계.md` + `07_TriggerBus_상세설계.md` + `08_RuntimeFactory_상세설계.md` + `09_BattleField_슬롯_상세설계.md`을 따른다.  
4) 해당 기준으로도 불명확하면 이 문서에 결정사항을 추가한 뒤 진행한다.

---

## 4. 변경 관리 규칙 (MVP 기간)

- 동결 범위 항목 변경은 반드시 `02_개발_로드맵.md`와 `03_MVP_전층_스펙.md` 동시 수정
- 변경 1건당 영향 문서(최소 3개) 동시 점검
- 체크리스트 문서(`03_MVP_전층_스펙.md`, `10_카드_런타임_매핑_상세.md`, `16_밸런스_규칙.md`) 중 최소 1개에 검증 항목 추가
- "권장/미정" 문구 사용 금지, 실행 가능 문구로 확정

## 6. 수락 기준 (Go/No-Go)

- Go:
  - 문서 간 MVP 범위 충돌 없음
  - 이슈 1~12가 각자 DoD/테스트를 가짐
  - 구현자 인수인계 시 질문 없이 시작 가능
- No-Go:
  - 범위 문구가 권장/추정 형태
  - 단일 정본 문서가 없는 항목 존재
  - 체크리스트-이슈-테스트 연결이 끊겨 있음
