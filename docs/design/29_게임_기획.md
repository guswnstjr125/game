## 3. 세계관

### 배경

- 플레이어 클래스는 원래 영웅
- 악마의 타락을 막기 위해 금기를 사용
- 죄인이 되어 지옥으로 추락
- 지옥 생존 과정에서 괴물 군단을 지휘

### 엔딩 구조

- 지옥 탈출 성공
- 현실 세계 붕괴 직전
- 플레이어는 지옥 군단의 군주가 됨

## 4. 게임 구조

### 층 구조

정본은 `03_MVP_전층_스펙.md`다.

- 총 5개 층 / 층당 **9노드** (전투 4 · 이벤트 2 · 엘리트 1 · 휴식 1 · 보스 1)
- MVP 맵은 **단일 경로**다. 경로 선택·분기 맵은 Post-MVP (`23` §6, `01` D-11)

### 스테이지 종류

| 종류 | MVP | 설명 |
|---|---|---|
| 일반 전투 | 포함 | 기본 전투 |
| 엘리트 전투 | 포함 | 강화 적 / 높은 보상 |
| 보스 | 포함 | 층 클리어 관문 |
| 이벤트 | 포함 | 리스크 ↔ 보상 선택 (8종) |
| 상점 | 포함 | 2~5층 노드 6 (확정) |
| 휴식 | 포함 | HP 30% 회복 또는 카드 강화 |
| 보물 | Post-MVP | MVP 노드에 없음 |
| 미믹 | Post-MVP | MVP 노드에 없음 |

### 층별 테마 및 학습 목표

| 층 | 테마 | 학습 목표 | 주요 적 |
|---|---|---|---|
| 1층 | 굶주림의 지옥 | 희생 시스템 | 굶주린 구울, 시체 쥐, 죄수 영혼 |
| 2층 | 화염의 지옥 | 상태이상 | 화염 정령, 재의 기사, 용암 슬라임 |
| 3층 | 피와 육체의 지옥 | 융합 | 살덩이 골렘, 혈육 포식자, 기형 악마 |
| 4층 | 심판의 지옥 | 포지션 전략 | 심판 기사, 처형 집행관, 사슬 수도사 |
| 5층 | 심연의 지옥 | 전체 시스템 종합 | 심연 감시자, 공허 악마, 절망 사도 |

## 5. 핵심 게임 루프

```
맵 이동
→ 전투
→ 카드 획득
→ 몬스터 운영 (희생 vs 융합 딜레마)
→ 덱 강화
→ 보스전
→ 다음 층
```

## 8. 메타 프로그레션

정본은 `26_메타_언락_설계.md`다. 런 밖에서 `META_SOUL`(타락의 영혼)과 `META_SIGIL`(심연 인장)로 클래스·카드 풀·유물 풀을 연다.

| 클래스 언락 | 비용 | 조건 |
|---|---|---|
| ELE | Soul 80 | 기본 |
| BEA | Soul 120 | 2층 1회 클리어 |
| HOL | Soul 150 | 3층 1회 클리어 |
| NEU | Soul 150 | 4층 1회 클리어 |

### 심연의 가마솥 (Post-MVP)

게임 종료 후 덱 카드 또는 유물 중 하나를 영구 제물로 바쳐 신규 클래스·몬스터·Lv4를 여는 구조는 **Post-MVP**다. MVP 메타는 위 언락 표만 사용한다.
