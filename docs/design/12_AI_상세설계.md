## 1. 공통 규칙

- AI는 **Intent 생성 + BattleAction Enqueue**만 수행
- **플레이어 턴 시작(드로우 직후)에 1회 Decide**로 이번 턴 행동을 확정하고 종류 아이콘만 공개. Queue 처리 중 재판단 금지 (`01` D-28)
- 대상은 Enemy Phase 실행 시점에 타겟 규칙으로 선택. 단일 공격은 아군 몬스터가 없을 때만 플레이어, 광역은 아군 전체 + 플레이어 (`01` D-29)
- `Stun` / `Bind` → `NoAction` (Bind는 희생 제외)
- 타겟 **Enqueue 시점 고정 금지** — Action Execute 시 재검증

```csharp
public interface IEnemyAI
{
    EnemyIntent DecideIntent(RuntimeEnemy self, BattleContext ctx);
    void CommitIntent(RuntimeEnemy self, EnemyIntent intent, BattleContext ctx);
}
```

## 2. AggressiveAI

**적용**: 구울, 화염 정령, Bruiser 계열

| 우선 | 조건 | 행동 | 타겟 |
|------|------|------|------|
| 1 | 후열 Living Enemy | 공격 | LowestHp |
| 2 | Front Player Ally | 공격 | FrontEnemy |
| 3 | 기본 | 공격 | FrontEnemy |

```csharp
EnemyIntent DecideIntent(RuntimeEnemy self, BattleContext ctx)
{
    if (self.StatusContainer.Has(Stun) || self.StatusContainer.Has(Bind))
        return EnemyIntent.None;

    var back = ctx.Targeting.LowestHp(ctx.Allies, preferBack: true);
    if (back != null && back.Position == Back)
        return EnemyIntent.Attack(back);

    return EnemyIntent.Attack(ctx.Targeting.FrontEnemy(self.Team));
}

void CommitIntent(...)
{
    ctx.QueueProcessor.Enqueue(new DamageAction(self, intent.Target, self.Attack.FinalValue));
}
```

## 6. BossPatternAI

### 6.1 구조

```csharp
public class BossPatternAI : IEnemyAI
{
    private BossPhaseData _phaseData;
    private int _turnCounter;
    private int _currentPhaseIndex;

    public void OnHpChanged(float hpRatio) { /* 페이즈 전환 */ }
}
```

### 6.2 HP 페이즈 전환

```
hpRatio <= 0.20 → Phase 3
hpRatio <= 0.50 → Phase 2
else → Phase 1

전환 시: OnPhaseChange Trigger → PresentationEvent
```

### 6.3 굶주림의 사제 (ENE_1F_BOS_001)

```csharp
EnemyIntent DecideIntent(...)
{
    int phase = GetPhase(ctx.Boss.HpRatio);
    int turn = _turnCounter % 3;

    if (phase == 3)
        return DoubleAttackIntent(); // 2 DamageAction Enqueue

    if (phase == 2)
    {
        if (turn == 0) return SummonIntent("GHO_MINION");
        if (turn == 1) return LifeStealIntent();
        return AoEIntent(6);
    }

    // Phase 1
    if (turn == 1) return ApplyWeakIntent(2);
    return SingleAttackIntent();
}
```

**광폭화 2회 행동**: `CommitIntent`에서 `DamageAction` 2개를 **순서대로** Main Queue Enqueue (동일 타겟 재검증).

## 7. AI 타겟 우선순위 (`06_전투_코어_상세설계.md` §16.3)

1. 처형 가능 (HOL Execute %)
2. 후열 Assassin
3. 상태이상 부여 대상
4. Front 기본

> 플레이어는 이 순위의 후보가 아니다. 단일 공격은 공격 가능한 아군 몬스터가 **하나도 없을 때만** 플레이어를 노리고, 광역은 아군 전체와 플레이어를 함께 맞힌다 (`01` D-29).
