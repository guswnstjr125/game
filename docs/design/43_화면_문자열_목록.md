## 9. 쓰는 규칙

- 문구에 `DiscardPile` 같은 코드 이름과 D 번호를 쓰지 않는다 (`01` D-58과 같은 규칙).
- 키는 `영역.항목` 형식이다. 새 문구는 해당 절에 행을 더하고 `ko.json`도 같이 고친다.
- 크레딧 내용(제작, 라이선스)은 출시 직전에 채운다 (`01` D-59).
