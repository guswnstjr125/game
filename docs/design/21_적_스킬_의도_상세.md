## 1. 공통 규칙

- `AI.Decide`는 Enemy Phase 시작 시 1회만 수행
- 행동은 `BattleAction`으로 Main Queue에 Enqueue
- `Bind/Stun` 상태면 `NoAction`
- 타겟은 Execute 시점 재검증
