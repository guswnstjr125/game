# 다크 레기온 — 적 28종 스킬·Intent 상세

> **문서 역할**: 적 28종의 행동 규칙을 구현 가능한 단위로 확정 (조건/행동/타겟/수치)
> **참조 문서**: 20_적_바이블, 12_AI_상세설계, 03_MVP_전층_스펙

## 1. 공통 규칙

- `AI.Decide`는 **플레이어 턴 시작(드로우 직후)** 에 1회만 수행하고, 종류 아이콘만 공개한다 (`01` D-28, `12` §1). Enemy Phase에서는 확정된 행동을 실행만 한다
- 행동은 `BattleAction`으로 Main Queue에 Enqueue
- `Bind/Stun` 상태면 `NoAction`
- 타겟은 Execute 시점 재검증

### 1.1 행동 선택 (`01` D-55)

§2~§6 표의 "행동 우선순위"는 아래 순서로 읽는다. 보스는 `14` Boss_TurnCycle 고정 순서를 따른다.

1. 표 위에서부터 **조건이 붙은 행동**을 본다. 조건이 참이고 **직전 턴에 쓴 행동이 아니면** 그 행동을 고른다. 확률 조건(예: 30%)은 `BattleRandom`으로 굴린다.
2. 고른 것이 없으면 **조건 없는 행동들을 표 순서대로 돌아가며** 쓴다. 적마다 순환 위치를 기억한다.
3. "대상 Poison 없음" 같은 대상 조건은 결정 시점에 그 조건을 채우는 아군이 하나라도 있으면 참이다. 실제 대상은 실행 시점에 고른다 (D-28).
4. Bind·Stun이면 `NoAction`이고, 순환 위치와 직전 행동 기록은 그대로 둔다.

예: 역병 수도사(`ENE_1F_ELT_002`, 조건 없는 행동 3개)는 Poison → Weak2 → 기본공격을 돈다. 굶주린 구울(`ENE_1F_GHO_001`)은 HP>50%일 때 30%로 강타를 쓰되 두 턴 연속으로는 쓰지 않는다.

## 8. 의도 아이콘 대응 (`01` D-48)

적 슬롯의 의도 아이콘은 6종이다 (D-28). 보스 행동(`14` Boss_TurnCycle Action)의 대응은 D-48 결정이다.

| 아이콘 | 보스 Action (D-48) | 일반 적 스킬 규칙 (D-52) |
|---|---|---|
| 단일 공격 | SingleAttack, Execute | 한 대상에게 피해를 주는 스킬 (기본 ATK, 강타, 처형) |
| 광역 공격 | AoE | 여럿에게 피해를 주는 스킬 (광역 피해, 연쇄) |
| 방어·버프 | — | 자신·적 편에 Shield·Taunt·ATK 상승·회복을 거는 스킬 |
| 디버프 | ApplyBurn, ApplyWeak, ApplyBind, RemoveShield, CrystalDrain, AddCurseCard | 피해 없이 플레이어 편에 상태이상·자원 방해를 거는 스킬 |
| 소환 | Summon | 적을 추가로 부르는 스킬 |
| 특수 | LifeSteal, ExecuteAura | 피해와 회복·지속 효과가 섞여 위 분류로 대비 방법이 드러나지 않는 스킬 |

- 한 턴에 행동이 여럿이면 피해가 있는 행동의 아이콘을 보여 준다 (광역 공격 > 단일 공격). 피해가 없으면 첫 행동의 아이콘 (D-52).
- #41(AI)에서 일반 적 스킬마다 위 규칙으로 아이콘을 매겨 이 표에 열로 적는다. 두 칸에 걸치는 스킬은 특수로 둔다 (D-52).
