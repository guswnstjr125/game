## 1. 현재 목표

```
1단계: 1~2층 NEC 플레이 가능 빌드 (UI·맵·세이브 포함)
2단계: 3~5층과 나머지 MVP (`03` 전층)
```

구체적으로:
- 전투 가능
- 카드 사용 가능
- 적 AI 동작
- 상태이상 적용
- 희생 가능
- 소환 가능
- 보스 패턴 동작
- 웨이브 진행 가능
- 승패 가능

### MVP 범위 고정 (`03_MVP_전층_스펙.md` 정본)

- 맵: 층당 9노드 **단일 경로** (5층 = 45노드)
- 노드: Battle 4 / Event 2 / Elite 1 / Rest 1 / Boss 1
- Shop: 2층+ 노드6에서 Event와 **30% 옵션 치환**
- Treasure / Mimic: **Post-MVP** (MVP 미등장)
- 풀 버전 맵 분기 규칙은 `23_콘텐츠_설계.md`·`24_콘텐츠_런타임_상세.md`의 Post-MVP 절을 참조

## 3. 구현 순서 (반드시 준수)

순서가 뒤집히면 구조가 붕괴된다.

```
1.  전투 코어 (BattleAction, BattleContext)
2.  Queue 시스템 (QueueProcessor, Main/Trigger/Death Queue)
3.  Runtime 시스템 (RuntimeUnit, RuntimePlayer, RuntimeEnemy)
4.  카드 시스템 (CardData, RuntimeDeck, CardResolver)
5.  상태이상 시스템 (StatusSystem, RuntimeStatusEffect)
6.  AI 시스템 (EnemyAI, TargetSelector)
7.  희생 시스템 (SacrificeSystem)
8.  소환 시스템 (SummonSystem, RuntimeSummon)
9.  보스 시스템 (BossPatternAI, BossPhase)
10. Stage / Wave 시스템 (StageGenerator, WaveData)
11. Battle Simulator 구현
12. 자동 밸런싱 구현
```

## 4. 단계별 일정 (재추정, `01` D-13)

6주 안에 5층·카드 92장만 적고 UI·맵·세이브가 빠져 있던 일정을 두 단계로 다시 잡았다. 주차는 구현 순서용 재추정이고, 완료 조건은 플레이 가능 여부다.

### 1단계 — 1~2층 플레이 가능 빌드 (약 5주)

범위: 층 1~2, 시작 클래스 NEC, 카드 약 30장(1층 풀 32장 안의 NEC·NEU), 보스 2종, 1~2층에 걸리는 이벤트, 단일 경로 맵, 전투·맵·보상 UI, Save/Load.

| 주차 | 내용 |
|---|---|
| 1 | 전투 코어, Queue, Runtime, Turn |
| 2 | 카드·덱·Resolver (약 30장) |
| 3 | 상태이상 8종, 1~2층 AI, 희생·소환 |
| 4 | 단일 경로 맵(9노드×2층), Wave, 보상, 보스 2종, 해당 층 이벤트 |
| 5 | 전투/맵/보상 UI, Save/Load로 이어하기 |

완료 조건: NEC로 1층을 깨고 2층 보스까지 저장 후 이어서 플레이할 수 있다.

### 2단계 — 나머지 MVP (약 4주)

범위: 3~5층, ELE·BEA·HOL·NEU, 나머지 드롭 카드와 융합 전용 6장, 보스 3종, 유물·상점 치환, 메타 언락, 연출, 시뮬레이터.

| 주차 | 내용 |
|---|---|
| 6~7 | 3~5층 적·보스, 융합 충전·레시피 |
| 8 | 나머지 클래스 카드, 유물, 상점 30% 치환, 이벤트 8종 전체 |
| 9 | 메타 언락, 전투 연출, Battle Simulator |

완료 조건: `03_MVP_전층_스펙.md`의 5층 런을 한 번에 플레이할 수 있다.
