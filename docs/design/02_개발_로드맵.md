## 1. 현재 목표

```
1단계: 1~2층 NEC 플레이 가능 빌드 (UI·맵·세이브·Lv1 융합 포함, `01` D-26)
2단계: 3~5층과 나머지 MVP (`03` 전층)
남은 일정: 1단계 3주 + 2단계 4주 (`01` D-83, 2026-11-22)
```

구체적으로:
- 전투 가능
- 카드 사용 가능
- 적 AI 동작
- 상태이상 적용
- 희생 가능
- 융합 가능 (Lv1+Lv1, `01` D-26)
- 소환 가능
- 보스 패턴 동작
- 웨이브 진행 가능
- 승패 가능

### MVP 범위 고정 (`03_MVP_전층_스펙.md` 정본)

- 맵: 층당 9노드 **단일 경로** (5층 = 45노드)
- 노드: Battle 4 / Event 2 / Elite 1 / Rest 1 / Boss 1 (2~5층은 Event 1 / Shop 1)
- Shop: **2~5층 노드6 확정** (`01` D-34). 상점 구현은 2단계, 1단계 빌드는 2층 노드6을 Event로
- Treasure / Mimic: **Post-MVP** (MVP 미등장)
- 풀 버전 맵 분기 규칙은 `23_콘텐츠_설계.md`·`24_콘텐츠_런타임_상세.md`의 Post-MVP 절을 참조

## 4. 남은 일정 (`01` D-83)

일정 추정 기준은 2026-11-22 (`01` D-83)이며, 현재 구현 상태는 2026-11-23 main `e8d0acb`를 기준으로 갱신한다. 아래 주 번호는 D-13·D-26의 1~10주와 다른 번호다.

끝난 구현은 남은 주에서 뺀다. Unity 프로젝트, 전투 코어, Queue, Runtime, 1단계 카드 32장, 상태이상, 1~2층 AI, 희생·소환·슬롯, Lv1 융합, 1~2층 런 골격·보상·휴식·이벤트·저주, 1단계 유물 8종, 1~2층 보스와 이벤트·휴식 화면 연결은 main에 있다. 저장·타이틀·일시정지 연결과 18노드 통합 회귀는 PR #113~#117에 있으며 병합되지 않았다.

완료 조건은 1단계 D-66, 2단계 5층 런 한 판이다. 아트(#32)는 이 일정에 없다. #28의 10런 측정은 1단계 플레이 가능 직후에 사람이 하고, 7주에 넣지 않는다.

### 남은 1단계 — 3주

범위는 D-26 그대로다. 층 1~2, NEC, 카드 32장(D-44)과 이벤트 저주 3장(D-45), 적 11종, 1~2층 이벤트 7종, Lv1 융합, 단일 경로 맵, 화면, Save/Load.

| 주 | 끝내는 것 | 이슈 |
|---|---|---|
| 1 | Unity에서 1층 노드 1 전투를 Core와 같이 플레이한다. 손패, 커맨드, 의도, HP, 턴 종료 | #46 |
| 2 | 타이틀, 18노드 맵, 보상, 휴식, 이벤트, 결과. 유물·이벤트·보상 임포터는 이 화면이 읽는 만큼 | #46·#35 |
| 3 | 그 화면에 저장을 연결한다. 새 런, 전투 중 종료 시 노드 재시작, 보상·이벤트 대기, 보스 직전 저장 후 이어하기 | #47 (`01` D-67, `32` PROG-07) |
