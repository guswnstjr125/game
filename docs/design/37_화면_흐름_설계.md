> **문서 역할**: 런 시작·종료 흐름, 1단계 화면 구성, 희생 안내 전투 문구 (이슈 #25·#26·#27)
> **참조 문서**: `27_UI_바인딩_설계.md` (ViewModel·Command), `14_Save_Load_상세.md` (저장), `26_메타_언락_설계.md` (메타 화폐), `03_MVP_전층_스펙.md` (노드), `01_MVP_설계_동결_선언.md` §7 D-27·D-28·D-32·D-37

## 1. 런 흐름 (#26)

### 1.1 화면 전이

```
타이틀
 ├─ 새 런 ──→ [1단계: NEC 고정 / 2단계: 클래스 선택(`41` §2)] ──→ 런 시작
 ├─ 이어하기 (런 저장이 있을 때만) ──→ 저장된 위치의 맵
 ├─ 설정
 └─ 종료

런 시작: 시작 덱 10장·시작 유물(D-06)·PlayerHP·골드(`04_밸런스_테이블.xlsx` Player_Stats), 1층 맵
  ↓
맵 ──→ 노드 진입
        ├─ Battle·Elite·Boss ──→ 전투 ──(승리)──→ 보상 ──→ 맵
        ├─ Event ──→ 이벤트 ──→ (ForcedBattle이면 전투) ──→ 맵
        ├─ Rest ──→ 휴식 ──→ 맵
        └─ Shop (2단계) ──→ 상점 ──→ 맵
  ↓ (노드 9 보스 승리)
층 클리어 ──→ 다음 층 맵 (1~4층) / 런 승리 (5층)
  ↓
결과 화면 ──→ 타이틀
```

### 1.2 런 종료 조건

| 결과 | 조건 |
|---|---|
| 승리 | 5층 보스 처치 |
| 패배 | PlayerHP ≤ 0, 노드 30턴 초과 (`03` §2) |
| 포기 | 일시정지 메뉴의 "런 포기" (확인 1회) → 패배로 처리 |

### 1.3 결과 화면

| 표시 | 내용 |
|---|---|
| 결과 | 승리 / 패배 / 포기 |
| 도달 | 층·노드, 진행 턴 수 |
| 기록 | 처치 수, 희생 수, 융합 수 |
| 메타 화폐 | 클리어한 층의 `Meta_Currency` 값을 **합산**해 지급 (예: 3층 클리어 후 패배 = Soul 40 + 55 + 70 = 165, Sigil 1). 업적 보상(`26` §3)은 따로 표시 |
| 새 업적 | 이번 런에서 달성한 업적 |

### 1.4 저장·이어하기

| 시점 | 처리 |
|---|---|
| 노드 클리어 | 런 저장 (`14` §4 스테이지 클리어) |
| 앱 백그라운드 | 런 저장 |
| 전투 중 종료 | 1단계는 전투 스냅샷을 쓰지 않는다. 이어하면 **그 전투 노드를 처음부터** 같은 시드로 다시 시작 |
| 런 종료 | 런 저장 삭제, `meta.json`에 화폐·업적·`TutorialDone` 반영 |

## 2. 화면 구성 (#25)

화면마다 **영역 배치 → 표시 항목 → 입력**의 순서로 적는다. ViewModel 이름은 `27` §2.

### 2.1 전투 화면

```
┌──────────────────────────────────────────────────────────────────┐
│ [층 1 · 노드 4]  [턴 3/30]                 [덱 12][버림 5][소멸 1] [Ⅱ] │  ← 상단 바
│                                                                  │
│   아군                                │   적                      │
│   [Back] [Middle] [Front]             │  [Front][Middle][Back][Ex1][Ex2] │  ← 전장
│    몬스터 슬롯 ×3                      │   의도 아이콘 / HP / 상태     │
│                                                                  │
│ [♥ 64/80]  [◆ Crystal 3]  [융합 충전 ●●○]                  [희생][융합] │  ← 자원 바
│ [ 손패 (최대 10장) ……………………………………………… ]                 [턴 종료]  │  ← 손패
└──────────────────────────────────────────────────────────────────┘
```

| 영역 | 표시 항목 | ViewModel |
|---|---|---|
| 상단 바 | 층·노드, 턴/30, 덱·버린 더미·소멸 더미 장수(누르면 목록), 일시정지 | BattleViewModel |
| 아군 슬롯 ×3 | 몬스터 그림, HP/MaxHP, ATK, DEF, Shield, 상태 아이콘, **커맨드 표시(검=공격 / 방패=방어)**, 공격 대상 연결선 | MonsterSlotViewModel |
| 적 슬롯 ×5 | 적 그림, HP, 상태 아이콘, **의도 종류 아이콘 1개**(단일 공격 / 광역 공격 / 방어·버프 / 디버프 / 소환 / 특수, D-28). Ex1·Ex2는 비어 있으면 숨김 | EnemySlotViewModel |
| 자원 바 | PlayerHP, Shield(있을 때), 플레이어 상태 아이콘(D-29), Crystal, 융합 충전(0~3) | PlayerViewModel |
| 손패 | 카드(비용·이름·효과 요약·강화 표시). 사용 불가 카드는 어둡게 | HandViewModel |

| 입력 | 동작 | 잠금 |
|---|---|---|
| 몬스터 카드 → 빈 아군 슬롯으로 끌기 | 소환. 슬롯이 가득 차면 거부(`09`) | Main Phase만 |
| 스킬·액션 카드 누르기 → 대상 누르기 | 카드 사용. 대상이 필요 없으면 바로 사용 | Main Phase만 |
| 아군 몬스터 선택 → [희생] | 확인 창에 "Crystal +N" 예상값 표시 후 희생 | Main Phase만 |
| [융합] | 손패의 같은 레벨 몬스터 카드 2장을 고르는 창. 비용·충전·예상 결과(고정 레시피면 결과, 랜덤이면 "랜덤") 표시 | Main Phase만, 충전 0이면 비활성 |
| 아군 몬스터 누르기 | 공격 ↔ 방어 전환 (D-27) | Main·Command Phase |
| 아군 몬스터(공격) 선택 → 적 슬롯 누르기 | 공격 대상 변경 | Main·Command Phase |
| 아군 몬스터 → 인접한 빈 슬롯으로 끌기 | 위치 변경 (`09`) | Main Phase만 |
| 카드·몬스터·적에 마우스 올리기 / 우클릭 | 상세 정보 (효과 전문, 상태이상 남은 턴). 올리기는 툴팁, 우클릭은 상세 창 | 항상 |
| [턴 종료] | Resolve → Enemy Phase 진행 | Main·Command Phase |

### 2.2 맵 화면

```
┌───────────────────────────────┐
│ [1층 · 굶주림]       [♥ 64/80] [골드 23] [유물 ▢▢] │
│                                 │
│   ⑨ 보스                         │
│   ⑧ 휴식                         │
│   ⑦ 전투   ← 노드는 아래에서 위로   │
│   ⑥ 이벤트 / 상점(2~5층)           │
│   ⑤ 엘리트                        │
│   ④ 전투                         │
│   ③ 이벤트                        │
│   ② 전투  ◀ 현재                  │
│   ① 전투  ✓                       │
│                    [덱 보기]      │
└───────────────────────────────┘
```

| 표시 | 내용 |
|---|---|
| 노드 | 9개 아이콘 세로 배치, 지난 노드 ✓, 현재 노드 강조. 단일 경로라 다음 노드만 누를 수 있음 |
| 상단 | 층 번호·테마 이름, HP, 골드, 유물 아이콘(누르면 효과) |
| 하단 | 덱 보기(카드 목록, 강화 표시) |

### 2.3 보상 화면

| 순서 | 내용 |
|---|---|
| 1 | 골드 획득 표시 (`Reward_BattleTable`) |
| 2 | 엘리트: 유물 3택1 / 보스: 보스 유물 1 (`REL_BOSS_*`, D-16) |
| 3 | 카드 3택1. **건너뛰기 가능** (D-37) |
| 4 | [계속] → 맵 |

### 2.4 휴식 화면

| 선택지 | 내용 | 비활성 조건 (`06_콘텐츠_마스터.xlsx` RestNode_Rules) |
|---|---|---|
| 회복 | MaxHP의 30% 회복. 회복 후 HP 미리보기 | HP가 MaxHP 이상 |
| 강화 | 덱에서 1장 선택 → 강화 전/후 비교(Cards_Upgrade, D-31) → 확정 | 강화 가능한 카드 없음 |

### 2.5 이벤트 화면

| 영역 | 내용 |
|---|---|
| 상단 | 이벤트 그림 |
| 본문 | 도입 문구 (`40_이벤트_화면_문구.md`, #33, `01` D-52) |
| 선택지 3개 | 조건을 못 채운 선택지는 어둡게 하고 조건 표시 (예: "골드 8 이상") |
| 결과 | 결과 문구 + 변화(HP·골드·카드·유물) 표시 → [계속] |

### 2.6 일시정지·설정

| 항목 | 내용 |
|---|---|
| 일시정지 | 계속 / 설정 / 런 포기 / 타이틀로(저장 후) |
| 설정 | BGM·효과음 볼륨, 화면 흔들림 Off/Low/Default, 연출 속도 x1/x1.5/x2, 색약 모드 On/Off, 기본 Off (`01` D-47) (`28` §6) |

### 2.7 화면 ↔ ViewModel

| 화면 | ViewModel |
|---|---|
| 타이틀 | TitleViewModel (HasRunSave) |
| 맵 | MapViewModel (Floor, Nodes, CurrentIndex) |
| 전투 | BattleViewModel 외 `27` §2 목록 |
| 보상 | RewardViewModel (Gold, RelicChoices, CardChoices) |
| 휴식 | RestViewModel (CanHeal, CanUpgrade) |
| 이벤트 | EventViewModel (EventId, Options, Result) |
| 결과 | ResultViewModel (Outcome, Stats, MetaGain) |
| 일시정지 | PauseViewModel (InBattle) |
| 설정 | SettingsViewModel (BgmVolume, SfxVolume, ScreenShake, AnimSpeed, ColorBlindMode) |

## 3. 희생 안내 전투 (#27, D-32)

첫 런의 1층 노드 1에서만 나온다. 1~3단계는 **차단형**(안내한 입력만 허용), 4~5는 2턴째에 나오는 **비차단형 팁**이다.

| 단계 | 문구 | 강조 | 허용 입력 | 다음 단계 조건 |
|---|---|---|---|---|
| 1 | "지옥에서 힘은 대가로 얻는다. 먼저 **수정 골렘 파편**을 소환하라. 비용은 없다." | 손패의 파편, 빈 아군 Front 슬롯 | 파편 소환 | 파편이 필드에 나옴 |
| 2 | "**영혼 추출**로 파편을 지정하고, 그 파편을 **희생**하라. 지정한 몬스터가 죽으면 카드를 뽑고, 희생한 몬스터는 Crystal이 된다." | 영혼 추출 카드 → 파편 슬롯(대상 지정) → [희생] 버튼 | 영혼 추출 사용(대상 파편, `01` D-42), 파편 희생 | Crystal 5, 카드 2장 드로우 |
| 3 | "얻은 Crystal로 군단을 세워라. **뼈 병사**와 **굶주린 구울**을 소환하라." | 두 카드, 빈 슬롯 | 두 카드 소환 | 두 마리가 필드에 나옴 |
| 4 (2턴) | "적 머리 위 아이콘은 이번 턴 적이 할 **행동의 종류**다. 공격이 오면 대비하라." | 적 의도 아이콘 | 모든 입력 | 3초 후 또는 누르면 닫힘 |
| 5 (2턴) | "몬스터를 누르면 **공격과 방어**를 바꿀 수 있다. 방어하면 이번 턴 Shield를 얻는다." | 아군 몬스터 커맨드 표시 | 모든 입력 | 3초 후 또는 누르면 닫힘 |

- 1단계 시작 시 Crystal 3. 2단계 후 Crystal 5(파편 +1, 피의 잔 +1), 3단계 후 3이 남는다.
- 안내 중에는 [턴 종료]와 [융합]을 잠근다. 3단계가 끝나면 모든 입력을 연다.
- 전투가 끝나면 `TutorialDone = true` (`14` MetaSaveDTO).
