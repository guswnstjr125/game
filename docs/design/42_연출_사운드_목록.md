## 1. 연출 방향

### 1.1 강조 단계

연출은 세 단계로 나눈다. 단계가 높을수록 길고 크게 보여 주며, 시간은 연출 속도 x1 기준이다 (x1.5·x2에서는 그 비율로 줄인다, `28` §6).

| 단계 | 시간 | 화면 | 입력 |
|---|---|---|---|
| 낮음 | ≤ 0.25초 | 트윈·아이콘 팝업만 | 막지 않음 |
| 중간 | 0.3~0.5초 | 트윈 + 숫자 강조 + 효과음 | 막지 않음 (연출 중 다음 입력은 대기열에 넣는다) |
| 높음 | 0.8~1.2초 | 화면 효과(어둡게·흔들림·색 플래시) + 효과음 + 문구 | 연출이 끝날 때까지 입력 잠금 (`27` InputLocked) |

### 1.2 핵심 순간의 단계

| 순간 | 단계 | 내용 |
|---|---|---|
| 카드 사용·드로우·일반 공격 | 낮음 | `28` §2·§3 그대로 |
| **희생** | 중간 (0.4초) | 몬스터가 붉게 번쩍이며 아래로 사라짐(`39` §4) → Crystal 숫자가 +N으로 튀어 오름 + `sfx_sacrifice` → `sfx_crystal_gain`. 희생은 매 턴 반복하는 핵심 행동이라 높음으로 두면 흐름이 끊긴다 |
| **융합** | 높음 (1.0초) | 재료 두 마리가 가운데로 모임 → 화면 살짝 어둡게 → 결과 몬스터 등장 + `sfx_fusion_complete`. 결과가 무작위(Random 레시피)면 0.2초 더 머문 뒤 이름 표시. 전투당 몇 번 안 되는 성장 순간이다 |
| **보스 페이즈 전환** | 높음 (1.2초) | 보스별 화면 효과(`28` §4) + 층 강조색 플래시(`39` §3) + `sfx_boss_phase` + 페이즈 문구("굶주림이 깨어난다" 같은 한 줄, 보스·페이즈마다 1개). 다음 페이즈의 행동이 바뀐다는 신호다 |
| 처형(Execute) | 중간 | `28` §2 strong shake 0.18초 + `sfx_execute_hit` |
| 보스 처치 | 높음 (1.2초) | 화면 멈춤 0.15초 → 흰 플래시 → `sfx_boss_down` → 결과·보상 |
| 플레이어 패배 | 높음 (1.0초) | 화면 desaturate → `bgm_defeat` |

### 1.3 보스 페이즈 문구

페이즈 전환 때 화면 가운데에 1.2초 동안 한 줄을 보여 준다. 페이즈 요약은 `14_보스_패턴.xlsx` Boss_Phase.

| 보스 | 페이즈 2 (HP 50% 이하) | 페이즈 3 (HP 20% 이하) |
|---|---|---|
| 굶주림의 사제 (1층) | "굶주림이 무리를 부른다" (소환·흡혈·광역) | "사제가 마지막 숨을 몰아쉰다" (2회 공격) |
| 재의 대군주 (2층) | "재가 다시 불붙는다" (Burn 강화) | "대군주가 불길 속으로 걸어 나온다" (Burn+공격) |
| 혈육의 어머니 (3층) | "살점이 갈라져 자식을 낳는다" (분열·광역) | "어머니가 상처를 핥는다" (2회+자힐) |
| 무죄의 심판관 (4층) | "심판의 칼날이 내려온다" (Execute 상향) | "판결은 이미 내려졌다" (2회+Vulnerable) |
| 절망의 군주 (5층) | "절망이 그림자를 일으킨다" (소환·Crystal) | "모든 빛이 꺼진다" (Crystal+2회) |

문구는 다음 페이즈 행동을 짐작하게 하는 것이 목적이다. 수치는 쓰지 않는다.

- 화면 흔들림 설정(Off/Low/Default)은 모든 단계의 흔들림에 적용한다. Off에서도 색 플래시와 문구는 남는다.
- 연출은 로직 결과를 바꾸지 않는다 (`28` §1). 입력 잠금은 View에서만 한다.

## 2. BGM

| ID | 쓰는 곳 | 1단계 |
|---|---|---|
| `bgm_title` | 타이틀·클래스 선택·메타 언락 | ✓ |
| `bgm_floor1` ~ `bgm_floor5` | 그 층의 맵·일반 전투·이벤트·휴식·상점 | 1·2층 ✓ |
| `bgm_elite` | 모든 층 엘리트 전투 | ✓ |
| `bgm_boss_1f` ~ `bgm_boss_5f` | 그 층 보스 전투 (굶주림의 사제·재의 대군주·혈육의 어머니·무죄의 심판관·절망의 군주) | 1·2층 ✓ |
| `bgm_victory` | 런 승리 결과 화면 (짧은 곡, 끝나면 반복 없음) | — (1단계에는 5층이 없음) |
| `bgm_defeat` | 런 패배·포기 결과 화면 (짧은 곡) | ✓ |
| `bgm_floor_clear` | 1~4층 보스 처치 후 다음 층으로 갈 때 (짧은 곡) | ✓ |

- 합계 **15곡**, 1단계 **8곡** (title, floor1·2, elite, boss_1f·2f, defeat, floor_clear).
- 보스 페이즈 전환은 곡을 바꾸지 않는다. `sfx_boss_phase` 스팅어를 겹쳐 재생하고, 페이즈 3에서는 BGM에 저역 통과 필터를 0.5초 동안 걸었다 푼다. 곡 하나로 세 페이즈를 다 쓴다.
- 곡 사이 전환은 0.5초 크로스페이드. 전투 → 보상 화면은 같은 층 곡을 이어서 튼다.
- 반복 곡은 1분 30초~3분 길이로, 끊김 없이 반복되게 만든다.

## 4. 제작·형식

| 항목 | 결정 |
|---|---|
| 출처 | 상업적 사용이 허용된 라이선스만 쓴다: CC0 또는 구매한 효과음·음악 팩. AI로 만든 음원을 쓰면 `39` §6.6 Steam AI 공개 규칙을 같이 적용한다 |
| 기록 | 파일마다 출처·라이선스를 `DarkLegion/Assets/_Project/Audio/_license.md`에 남긴다 (빌드에 넣지 않음) |
| 형식 | BGM: OGG, 44.1kHz 스테레오, Streaming. SFX: WAV 원본 → Unity에서 Vorbis 압축, Decompress On Load |
| 믹서 | Unity AudioMixer 그룹 3개: BGM, SFX, UI. 설정의 BGM 볼륨은 BGM 그룹, 효과음 볼륨은 SFX·UI 그룹 (`37` §2.6) |
| 동시 재생 | 같은 SFX는 0.05초 안에 한 번만 재생한다 (광역 공격의 피격음이 겹쳐 커지지 않게) |
| 파일 이름 | 위 ID 그대로 (`sfx_sacrifice.wav`). 1단계는 같은 이름의 무음 또는 임시 소리로 먼저 넣고 나중에 교체 |
| 연결 | Presentation 계층의 `AudioCatalog`(ID → AudioClip)에서 찾는다. 로직은 ID만 알고 AudioClip을 모른다 (`05` §1 Rule 5) |

## 5. `28` 문서와의 관계

- `28` §2·§3은 액션별 연출과 타이밍의 정본이다. 이 문서는 그 위에 강조 단계(§1)와 전체 소리 목록(§2·§3)을 더한다.
- `28` §2의 `status_apply` 하나는 §3.4의 8개로 나눈다.
