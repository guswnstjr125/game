## 2. ID 규칙

### MON_ID (몬스터 런타임/바이블)

```
MON_{CLASS}_{LEVEL}_{번호3자리}

예) MON_NEC_L1_001, MON_ELE_L4_001, MON_NEU_L2_001
```

- `CLASS`: NEC / ELE / BEA / HOL / NEU
- `LEVEL`: L1 / L2 / L3 / L4
- 소환 카드와 연동 시 `Card_ID` = `17_카드_데이터베이스.md`의 `{CLASS}_MON_{번호}` (예: `NEC_MON_001`)

### Acquire (획득 방법)

| 값 | 의미 |
|----|------|
| 소환 카드 | 08 Monster 카드로 덱에 존재 |
| 융합 전용 | 융합 결과만 획득, 카드 없음 |
| 융합/토큰 | 스킬·액션으로만 생성 |
| 특수 해금 | 심연의 가마솥·메타 해금 |

## 4. 융합 규칙 (`04_시스템_설계.md`·`23_콘텐츠_설계.md`·`13_희생_융합_시스템_상세.md` 정본)

- 같은 레벨 몬스터 카드 **2장 소멸** → 상위 레벨 1장
- 노드 3·6·9 클리어마다 **융합 충전 +1** (최대 3), 전투 중 손패 2장 융합 (`01` D-03). 레시피·랜덤 풀은 `01` D-21·D-22
- 결과: **고정 레시피 30%** / **랜덤 70%** (클래스 풀)
- **NEU + 클래스**: 50% 클래스 상위 / 50% NEU 상위
- 소재 카드는 Exhaust 아님 **완전 소멸** (DeadCard)

상세 레시피: `09_몬스터_바이블.xlsx` → **Fusion_Recipes** 시트

## 5. PP·밸런스 검증

```
PP = HP × 0.4 + ATK × 1.2 + DEF × 0.8
```

| 레벨 | Crystal | PP 목표 |
|------|---------|---------|
| Lv1 | 0~1 | 7.0 ~ 10.0 |
| Lv2 | 2 | 11.0 ~ 18.0 |
| Lv3 | 3 | 19.0 ~ 30.0 |
| Lv4 | 4 | 31.0 ~ 50.0 |

- `Balance_Flag` ≠ OK → 04 의도적 이탈 또는 수정 필요
- Simulator 우선: `17_카드_데이터베이스.md` §7 (지옥불 드래곤, 광폭한 곰, 발키리, 죽음의 소용돌이 등)
