## 1. 공통 Boss SO

```csharp
[CreateAssetMenu(menuName = "DarkLegion/BossPhaseData")]
public class BossPhaseData : ScriptableObject
{
    public string BossId;
    public List<BossPhaseEntry> Phases;
}

public class BossPhaseEntry
{
    public float HpThreshold;      // 이 비율 이하로 내려가면 진입
    public List<BossPatternStep> PatternCycle;
}

public class BossPatternStep
{
    public int TurnIndex;          // 사이클 내 턴 (0..n-1)
    public SkillData Skill;
    public bool EnqueueTwice;      // 광폭화 2행동
}
```

## 2. 1층 — 굶주림의 사제 (ENE_1F_BOS_001)

### 2.1 스탯 (1층 1-9 보스, 04)

| 항목 | 값 |
|------|-----|
| HP | 47 |
| ATK | 12 |
| DEF | 1 |
| 배율 | HP×2.8, ATK×2.0 |

### 2.2 Phase

| Phase | HP% | 핵심 |
|-------|-----|------|
| 1 | 100~50 | 단일 타격, Weak 부여 |
| 2 | 50~20 | 소환 1, 흡혈, 광역 6 |
| 3 | 20~0 | **매 턴 2회** 기본 공격 |

### 2.3 턴 사이클 (Phase 1 예)

| 턴 | 행동 |
|----|------|
| 0 | 단일 공격 (Front 우선) |
| 1 | Weak 2턴 (Back 우선) |
| 2 | 단일 공격 |

### 2.4 페이즈 전환 연출

- Phase2: `PresentationEvent.BossPhase` + BGM 스텅
- Phase3: 화면 Vignette + `OnPhaseChange` → UI 페이즈 아이콘

### 2.5 공략 힌트 (설계 의도)

- Phase2 소환물을 먼저 정리하지 않으면 흡혈로 장기전
- Phase3는 Shield·희생 타이밍으로 버티기 — DPS 체크

## 3. 2층 — 재의 대군주 (ENE_2F_BOS_001)

| 항목 | 값 |
|------|-----|
| HP / ATK / DEF | 59 / 14 / 2 |

| Phase | HP% | 턴 사이클 |
|-------|-----|-----------|
| 1 | 100~50 | T0: 전장 Burn+2 → T1: 단일 공격 → T2: 광역 4 |
| 2 | 50~20 | T0: Burn+3 전장 → T1: 단일×2 → T2: 광역 8 |
| 3 | 20~0 | 매 턴: Burn+1 전장 + 단일 공격 |

**설계 의도**: Burn 정리 없이 장기전 시 누적 피해 폭증. ELE 빌드 역학 테스트.

## 4. 3층 — 혈육의 어머니 (ENE_3F_BOS_001)

| 항목 | 값 |
|------|-----|
| HP / ATK / DEF | 73 / 16 / 2 |

| Phase | HP% | 턴 사이클 |
|-------|-----|-----------|
| 1 | 100~50 | T0: 단일 → T1: 아군 희생 유도(Weak 전장) → T2: 흡혈 50% |
| 2 | 50~20 | **HP 50% 진입 시** ENE_3F_FLS_003 분열 소환 ×1 · T0: 광역 6 → T1: 흡혈 |
| 3 | 20~0 | 매 턴 2회 공격 + 자힐 6 |

**설계 의도**: 분열체·희생 딜레마. 융합 층과 시너지.

## 5. 4층 — 무죄의 심판관 (ENE_4F_BOS_001)

| 항목 | 값 |
|------|-----|
| HP / ATK / DEF | 87 / 18 / 3 |

| Phase | HP% | 턴 사이클 |
|-------|-----|-----------|
| 1 | 100~50 | T0: 단일 → T1: Bind 1턴(Front) → T2: Execute 판정 (HP≤30% 단일) |
| 2 | 50~20 | T0: 전장 Execute 임계 **25%로 상향** 오라 2턴 → T1: 광역 7 → T2: Shield 제거 |
| 3 | 20~0 | 2회 공격 + Vulnerable 2턴(전장) |

**설계 의도**: HOL 처형·포지션 교육. Front 보호 실패 시 처형 위험.

## 6. 5층 — 절망의 군주 (ENE_5F_BOS_001)

| 항목 | 값 |
|------|-----|
| HP / ATK / DEF | 101 / 22 / 3 |

| Phase | HP% | 턴 사이클 |
|-------|-----|-----------|
| 1 | 100~50 | T0: Crystal -1 → T1: 단일 → T2: 덱에 **허무** 저주 카드 1장 추가 |
| 2 | 50~20 | T0: ENE_5F_ABY_002 소환 → T1: 광역 6 → T2: Crystal -2 |
| 3 | 20~0 | 매 턴: Crystal -1 + 2회 공격 |

**허무 카드**: Cost 1, Exhaust, 효과 없음 (연출만). 최대 덱 5장 제한은 post-MVP.

**설계 의도**: 자원·덱 압박 최종 시험. 1~4층 시스템 종합.
