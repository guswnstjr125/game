# 다크 레기온 — MVP 이슈 초안 (1~12)

> 기준: `30_MVP_구현_이슈_템플릿.md`  
> 범위: MVP 정본(`03_MVP_전층_스펙.md`) 우선, Post-MVP 항목은 제외 또는 폴백만 반영

---

## #1 전투 코어 골격 구현

- **제목**: `[#1] BattleAction/BattleContext 기반 전투 코어 구현`
- **요약**: 전투 루프에서 공통 컨텍스트를 공유하고, 액션 단위 실행 흐름을 고정한다.
- **완료 조건**
  - `BattleAction` 실행/취소/로깅 훅 동작
  - `BattleContext`에 턴/유닛/큐/난수/전투상태 접근 일원화
  - 승패 판정 진입 지점 고정
- **테스트**
  - 기본 공격 액션 10회 연속 실행
  - 중간 사망 발생 시 전투 상태 정상 전이

## #2 Queue 처리 순서 구현

- **제목**: `[#2] Main/Trigger/Death Queue Flush 순서 구현`
- **요약**: 큐 우선순위를 고정해 트리거/사망 처리의 일관성을 보장한다.
- **완료 조건**
  - Flush 순서가 설계(Death 우선 포함)와 일치
  - 재귀 트리거에도 무한루프 없이 종료
  - 큐 처리 로그로 디버깅 가능
- **테스트**
  - 사망 트리거 연쇄 케이스
  - Trigger enqueue 폭주 보호

## #3 Runtime 유닛 계층 구현

- **제목**: `[#3] RuntimeUnit/RuntimePlayer/RuntimeEnemy 계층 구현`
- **요약**: 런타임 전투 객체를 데이터와 분리해 상태 갱신을 안정화한다.
- **완료 조건**
  - HP/ATK/DEF/상태이상 공통 처리
  - 플레이어/적 전용 속성 분리
  - 런타임 생성/소멸 라이프사이클 고정
- **테스트**
  - 유닛 생성/사망/제거 반복
  - 팀별 타겟 필터 정상 동작

## #4 카드 시스템 기본 구현

- **제목**: `[#4] CardRegistry/Deck/Hand/Discard/Exhaust 구현`
- **요약**: 카드 이동 규칙과 턴 단위 패 관리의 기반을 완성한다.
- **완료 조건**
  - Draw/Discard/Exhaust 규칙 반영
  - 턴 시작/종료 시 핸드 처리 일관성
  - 카드 비용 소비 및 사용 제한 동작
- **테스트**
  - 덱 고갈/셔플
  - Ethereal 카드 턴 종료 처리

## #5 카드 92장 ResolverSpec 매핑

- **제목**: `[#5] 카드 92장 ResolverSpec 등록 및 CardId 실행 검증`
- **요약**: 카드명을 배제하고 CardId 기반으로 실행 가능하도록 매핑을 완료한다.
- **완료 조건**
  - 92장 누락 없이 등록
  - `TargetRule` enum 고정
  - `EffectDefinition[]` 직렬화/역직렬화 검증
- **테스트**
  - 카드 샘플 실행 회귀
  - 잘못된 CardId 안전 실패 처리

## #6 상태이상 시스템 구현

- **제목**: `[#6] Burn/Poison/Weak/Vulnerable 상태이상 시스템 구현`
- **요약**: 턴틱/피해/증감 규칙을 일관된 엔진으로 구현한다.
- **완료 조건**
  - 턴 시작/종료 Tick 타이밍 고정
  - 중첩/지속 턴 처리 규칙 일치
  - 상태 부여 저항/면역 처리 경로 확보
- **테스트**
  - 중첩 상한/해제 케이스
  - 다중 상태 동시 적용

## #7 AI/타겟팅 구현

- **제목**: `[#7] EnemyAI 우선순위 로직 및 타겟 규칙 구현`
- **요약**: 적 행동 우선순위와 Front/Back 규칙을 설계대로 고정한다.
- **완료 조건**
  - Aggressive/Defensive/Control/Summon 패턴 반영
  - 타겟팅 규칙(Front 우선/후열 우선) 반영
  - 의도(Intent) 출력과 실제 행동 일치
- **테스트**
  - 적 28종 샘플 패턴 검증
  - 타겟 부재 시 폴백 타겟 검증

## #8 희생/소환/슬롯 충돌 구현

- **제목**: `[#8] Sacrifice/Summon 및 BattleField 슬롯 충돌 규칙 구현`
- **요약**: 아군 3슬롯/적 5슬롯 규칙과 교체/거부 처리를 구현한다.
- **완료 조건**
  - FullField 몬스터 소환 거부(Cost 미소모)
  - 토큰 소환 시 `WaitingReplace` 교체 처리
  - Wave 시작 시 토큰 제거/몬스터 유지
- **테스트**
  - 슬롯 가득 참 케이스
  - Death 이후 Occupant 해제 검증

## #9 보스 패턴 구현

- **제목**: `[#9] 1~5층 보스 패턴 구현`
- **요약**: 보스 페이즈/사이클/특수기 로직을 적용한다.
- **완료 조건**
  - 보스 5종 패턴 동작
  - 페이즈 전환 조건 정상
  - 특수 행동(소환/처형/크리스탈 압박) 반영
- **테스트**
  - 각 보스 3회 이상 시뮬
  - 페이즈 경계 조건 회귀

## #10 Stage/Wave/이벤트/보상 구현

- **제목**: `[#10] MVP Stage/Wave + 이벤트/보상/상점 치환 구현`
- **요약**: 5층 x 9노드 단일 경로와 보상 표를 실제 런 흐름에 연결한다.
- **완료 조건**
  - 층당 9노드 템플릿 반영
  - 이벤트 4종 반영
  - 상점 옵션 치환(2층+ 노드6 Event 30%) 반영
  - `StageType.Mimic` 입력 안전 폴백(Treasure 처리)
- **테스트**
  - 1~5층 완주 시나리오
  - 보상 수치 `Reward_BattleTable` 대조

## #11 Battle Simulator 구현

- **제목**: `[#11] Battle Simulator 실행 파이프라인 구현`
- **요약**: 자동 전투 반복 실행과 결과 수집 파이프라인을 구성한다.
- **완료 조건**
  - 대량 배치 실행 가능
  - 승률/턴수/사망 원인 수집
  - 시드 고정 재현 가능
- **테스트**
  - 동일 시드 재실행 동일 결과
  - 실패 리플레이 로그 확보

## #12 밸런스 자동 검증 구현

- **제목**: `[#12] 밸런스 자동 검증(OTK/무한루프 포함) 구현`
- **요약**: 밸런스 체크리스트를 자동/반자동 검증 루프로 연결한다.
- **완료 조건**
  - PP/코스트/상태 부여량 검증 리포트
  - 승률 목표 범위 리포트
  - OTK/무한루프 탐지 결과 저장
- **테스트**
  - 밸런스 주의 카드 세트 우선 검증
  - 임계값 변경 시 리포트 갱신 확인
