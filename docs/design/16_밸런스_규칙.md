## 1. 파워 포인트 (PP) 공식

```
PP = HP × 0.4 + ATK × 1.2 + DEF × 0.8
```

모든 몬스터/적 수치의 기준점. 카드 비용 적정성 판단에도 사용.

---

## 2. 층별 적 스케일링 공식

**스테이지인덱스**는 층 안에서의 노드 순서다. 노드 1 = `0`, 노드 9(보스 노드) = `8`. 범위는 **0~8**이다. 노드 번호(1~9)를 그대로 넣지 않는다.

기준값은 HP 14, ATK 5, DEF 1. 일반 스탯은 아래 식을 계산한 뒤 **반올림**(0.5는 올림)해 `04_밸런스_테이블.xlsx` **Floor_Scale** 및 이 절의 표와 맞춘다.

```
적 HP  = round( 기준HP  × (1 + 0.29 × (층 - 1)) × (1 + 스테이지인덱스 × 0.023) )
적 ATK = round( 기준ATK × (1 + 0.18 × (층 - 1)) × (1 + 스테이지인덱스 × 0.028) )
적 DEF = round( 기준DEF × (1 + 0.22 × (층 - 1)) × (1 + 스테이지인덱스 × 0.027) )
```

- 층 계수: HP +29%, ATK +18%, DEF +22%
- 노드 계수: HP +2.3%, ATK +2.8%, DEF +2.7% per 스테이지인덱스
- 예시: 1층 노드 9(인덱스 8) HP = round(14 × 1.184) = round(16.576) = **17**

## 3. 보스 배율

```
보스 HP  = Floor_Scale / Boss_List 확정 정수 (47 / 59 / 73 / 87 / 101)
보스 ATK = 일반 ATK × 층별 ATK배율 후 확정 정수 (8 / 9 / 11 / 14 / 16)
보스 DEF = floor( 반올림 전 일반 DEF(스테이지인덱스 8) × 1.5 )
```

보스 DEF의 피승수는 인덱스 8의 **반올림 전** 일반 DEF다. 그 값에 1.5를 곱한 뒤 내림하면 Excel 보스 DEF **1 / 2 / 2 / 3 / 3**이다 (`14_보스_패턴.xlsx` Boss_Stats).

| 층 | ATK 배율 | 비고 |
|---|---|---|
| 1~3 | **1.5** | 1층 기준 ATK 8 (일반 5×1.5). Front Lv1 즉사 방지 |
| 4~5 | **1.75** | 후반 압박. 확정 ATK 14 / 16 |

### 층별 보스 설계 기준 (예상 아군 전력)

| 층 | 예상 전력 | 보스 역할 |
|---|---|---|
| 1 | Lv1 Front 2~3체 + 희생 타이밍 | 패턴·Phase 학습 (즉사 금지) |
| 2 | Lv1~2, Burn/Poison 관리 | 상태이상 누적 시험 |
| 3 | Lv2 중심 (융합 본격화) | 희생·융합 딜레마 |
| 4~5 | Lv2~3 | 포지션·자원·종합 |

- 너무 높으면 소모전, 너무 낮으면 보스 패턴 볼 시간 없음
- 확정 수치: `01` §7 **D-05**, 표 §2 BossATK 열

## 4. 카드 비용 효율 기준

```
Crystal 1당 PP 목표: 7~9
범위를 벗어나는 카드는 의도적 이탈로 문서에 명시 필요
```

| Crystal | 기대 PP | 즉발 효과 기준 | 지속 효과 기준 | 주요 용도 |
|---|---|---|---|---|
| 0 | ≤6 | 피해 2~3 또는 Burn +1 | Shield +1 | 덱 윤활유, 제물용 |
| 1 | 7~10 | 피해 4~6 또는 드로우 1 | Burn +2, Poison +2 | Lv1 몬스터 소환 |
| 2 | 11~18 | 피해 6~10 또는 광역 4 | 상태이상 콤보 | Lv2 몬스터 / 핵심 스킬 |
| 3 | 19~30 | 광역 8~12 또는 처형 | 강화 지속효과 | Lv3 몬스터 / 강력 스킬 |
| 4 | 31~50 | 게임체인저급 | 전장 변화 | Lv4 전설 전용 |

|---|---|---|---|

## 7. 처형 HP 기준선

```
처형 발동 HP 비율 = 목표HP × 처형기준
```

| 처형 기준 | 비율 | 적용 카드 / 몬스터 |
|---|---|---|
| Lv1 처형 | 20% | 이단 심판관, 죽음의 시선 |
| Lv2 처형 | 30% | 고위 심판관 |
| Lv3 처형 | 35% | 집행인 연계 |
| Lv4 처형 | 40% | 발키리 (광역 40%) |
| 특수 처형 | 50% | HOL_ACT_002 최후의 심판 |

## 8. Battle Simulator 목표 기준

> **1차 지표는 런 단위**다. 전투당 승률을 독립 확률로 곱해 런 클리어를 추정하지 않는다 (`01` §7 **D-04**).

| 항목 | 기준 | 비고 |
|---|---|---|
| **런 클리어율** (시뮬 봇, 시드 충분) | **30~45%** | 1차 Go/No-Go |
| 전투당 평균 PlayerHP 손실 · 일반 | **2~4** | D-14 |
| 전투당 평균 PlayerHP 손실 · 엘리트 | **6~10** | D-14 |
| 전투당 평균 PlayerHP 손실 · 보스 | **10~15** | 층당 예산: `01` D-14 표 |
| 평균 전투 턴 | 4~8턴 | |
| 전투당 승률 (참고) | 일반≥75% / 엘리트≥60% / 보스≥45% | 덱 성장·의존. 독립곱 금지 |
| 이벤트 HP 증감 (2차 지표) | 별도 수집 | D-14 예산 밖. 피의 제단 −20, 악마 계약 MaxHP −10, 잊힌 제단 +15 등은 런 편차로 따로 본다 |

### Simulator 수집 데이터

- 승률
- 평균 턴 수
- 평균 피해량
- 상태이상 효율
- 희생 횟수 / 융합 횟수
- 카드 사용률
- 사망 횟수

### Simulator 탐지 대상

- OTK (One Turn Kill)
- 무한 루프
- 무한 드로우
- 특정 카드 과성능
- 특정 몬스터 독점
- 상태이상 무한 중첩

## 10. BalanceConfig ScriptableObject 필드 목록

```csharp
// 층 스케일링
float hpScalePerFloor    = 0.29f;
float atkScalePerFloor   = 0.18f;
float defScalePerFloor   = 0.22f;
float stageHpPerNode     = 0.023f; // 스테이지인덱스 0~8
float stageAtkPerNode    = 0.028f;
float stageDefPerNode    = 0.027f;

// 보스 배율
float bossHpMultiplier   = 2.8f; // 표시 HP는 Floor_Scale 정수 정본
// 층별 ATK 배율: 1~3층 1.5, 4~5층 1.75 (단일 상수 대신 FloorBossAtkMult[])
float bossAtkMultiplier  = 1.5f; // 기본(1~3층). 4~5층은 1.75f
float bossDefMultiplier  = 1.5f; // 적용: floor(반올림 전 DEF × 1.5)

// 카드 비용 효율
float ppPerCrystalMin    = 7f;
float ppPerCrystalMax    = 9f;

int sacrificeCrystalLv3  = 3;

// 처형 기준
float executeThresholdLv1 = 0.20f;
```

## 11. 밸런스 검증 체크리스트

신규 카드/몬스터 추가 시 아래를 확인할 것.

- [ ] PP 계산값이 레벨 목표 범위 내인가?
- [ ] Crystal 비용 대비 효과가 7~9 PP 범위인가?
- [ ] 특수능력으로 스탯 감산을 적용했는가?
- [ ] 처형 기준이 레벨별 기준선을 따르는가?
- [ ] 상태이상 부여량이 비용 기준을 따르는가?
- [ ] 의도적 이탈 카드는 설계 이유가 문서에 명시되어 있는가?
- [ ] Simulator 승률이 목표 범위 내인가?
- [ ] OTK / 무한 루프 탐지 통과했는가?
- [ ] 피해 계산이 D-01 공식(DEF 차감 후 최소 1, 틱 피해 DEF 무시)과 일치하는가? (`01` §7)
- [ ] 소환 턴 행동(D-02)·융합 충전/비용(D-03) 규칙이 Simulator에 반영됐는가?
