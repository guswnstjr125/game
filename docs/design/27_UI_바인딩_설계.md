# 다크 레기온 — UI 바인딩 설계

> **문서 역할**: ViewModel, Command, 입력 잠금, Presentation 분리
> **참조 문서**: 05_기술_아키텍처 §10, 04_시스템_설계 §3, 06_전투_코어_상세설계

---

## 1. 원칙

```
Runtime → ViewModel → View
UI → ViewModel → Command → BattleAction → Queue
UI → Runtime 직접 수정 금지
```

---

## 2. ViewModel 목록

| ViewModel | 관찰 속성 (예) | Command |
|-----------|----------------|---------|
| BattleViewModel | Phase, Turn, InputLocked | RequestCardPlay, RequestSacrifice, RequestFusion |
| PlayerViewModel | Hp, Crystal, MaxCrystal | — |
| HandViewModel | Cards (id, cost, playable) | SelectCard, Deselect |
| MonsterSlotViewModel ×3 | UnitId, Hp, Intent, StatusIcons | SelectUnit, MovePosition |
| EnemySlotViewModel ×3 | Hp, Intent, StatusIcons | — |
| QueueDebugViewModel | Main/Trigger/Death counts | — (에디터) |

---

## 3. 카드 플레이 흐름

```
HandView.OnCardClicked(cardId)
→ HandViewModel.Select(cardId)
→ BattleViewModel.RequestCardPlay(cardId, targetUnitId)
→ CardResolver.Resolve → Enqueue actions
→ QueueProcessor.Process()
→ BattleViewModel.OnBattleStateChanged (이벤트)
→ 각 ViewModel RefreshFrom(Runtime)
→ PresentationPlayer.Play(events)  // 로직 후 연출
```

---

## 4. 입력 잠금

| 상태 | InputLocked |
|------|-------------|
| Queue Processing | true |
| Enemy Phase | true |
| Main Phase | false |

해제: `QueueProcessor.Process()` 완료 콜백 → `BattleState = PlayerPhase`

---

## 5. BattleViewModel (스케치)

```csharp
public class BattleViewModel
{
    public bool InputLocked { get; private set; }
    public IReadOnlyList<PresentationEvent> PendingVfx { get; }

    public void RequestCardPlay(string cardId, string targetUnitId)
    {
        if (InputLocked) return;
        var actions = _cardResolver.Resolve(...);
        _context.QueueProcessor.EnqueueAll(actions);
        RunQueueAndRefresh();
    }

    private void RunQueueAndRefresh()
    {
        InputLocked = true;
        _queueProcessor.Process();
        RefreshAll();
        InputLocked = false;
        _presentation.Play(_pendingEvents);
    }
}
```
