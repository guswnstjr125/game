## 1. RuntimeStatusContainer

```csharp
public class RuntimeStatusContainer
{
    private List<RuntimeStatusEffect> _effects;

    public void Add(RuntimeStatusEffect e);
    public void Remove(StatusType type, RuntimeUnit source = null);
    public RuntimeStatusEffect Get(StatusType type);
    public bool Has(StatusType type);
    public IReadOnlyList<RuntimeStatusEffect> All { get; }

    public void TickTurnStart(RuntimeUnit owner, BattleContext ctx);
    public void TickTurnEnd(RuntimeUnit owner, BattleContext ctx);
}
```

### Tick 순서 (유닛당)

```
TurnStart → Stun/Bind 검사 (행동 가능 플래그)
Main Phase / Command / Resolve
TurnEnd → Burn, Poison 틱 → Shield 전량 제거 → Duration 만료
```

지속형(Weak·Vulnerable·Bind·Stun)은 TurnEnd에 1씩 줄어든다. Enemy Phase나 TurnEnd 처리 중에 걸린 상태는 그 턴의 TurnEnd에는 줄이지 않는다 (`01` D-57).

## 2. 상태이상 8종

### Burn — `STATUS_BURN`

| 항목 | 값 |
|------|-----|
| 중첩 | Stack, 턴종 -1 |
| 시점 | TurnEnd |
| 효과 | `damage = stacks × 1` → DamageAction Enqueue |
| 최대 | 20 (MVP 확정) |
| Trigger | OnDamageDealt 후 OnTurnEnd |

```csharp
// TurnEnd Tick
foreach (burn in owner.StatusContainer.GetAll(Burn))
{
    ctx.Queue.Enqueue(new DamageAction(source, owner, burn.Stack, ignoreDef: true));
    burn.Stack -= 1;
    if (burn.Stack <= 0) Remove(burn);
}
```

### Poison — `STATUS_POISON`

- Stack 유지, TurnEnd 피해 stacks×1, **전투 종료 시 제거**
- **최대 20** (`01` D-08). Burn과 같은 상한. Wave 사이에 스택은 유지되고, 20을 넘는 추가는 잘린다.

### Weak — `STATUS_WEAK`

- Duration 2턴. **피해 계산에서만** 공격 측 기본피해에 ×0.75를 곱한다 (`01` D-01·D-56). `Attack` 스탯의 Modifier로 걸지 않는다 (두 번 적용 방지)

### Vulnerable — `STATUS_VULNERABLE`

- Duration 2턴, 피해 `× 1.25`
- Weak(×0.75)와 함께면 상태 배율은 **0.75 × 1.25 = ×0.9375** (`01` D-01). DEF 차감은 Weak 적용 다음, Vulnerable 적용 앞이다.

### Shield — `STATUS_SHIELD`

- Stack = 흡수량, Damage 직전 차감, **TurnEnd 전량 소멸**

### Taunt — `STATUS_TAUNT`

- 패시브, AI Front 대신 Taunt 유닛 우선 (Targeting)

### Bind — `STATUS_BIND`

- N턴, 공격/스킬 차단, **희생 허용**

### Stun — `STATUS_STUN`

- TurnStart에 1턴 행동 불가, 턴 종료 시 제거

|------|----------|

```

→ OnStatusApplied Trigger
```
